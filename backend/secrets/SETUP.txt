Firebase / web push configuration
===================================

Primary template: backend/.env.example (copy to backend/.env)

Never commit service account JSON. Use env vars only.

--- Local development ---

1. Copy backend/.env.example → backend/.env and set:
   - FIREBASE_* (Admin send)
   - VITE_FIREBASE_* (browser push — also used by frontend Vite + service worker)
2. Optional frontend/.env for VITE_API_URL, VITE_GEOAPIFY only (overrides)
3. Service account file (gitignored): backend/secrets/firebase-admin.json
   OR FIREBASE_SERVICE_ACCOUNT_JSON_B64 in backend/.env
4. cd frontend && npm run dev  (generates public/firebase-messaging-sw.js from env)

--- VPS / Docker (runtime) ---

app.env + staging.app.env:
  FIREBASE_PROJECT_ID=
  FIREBASE_SERVICE_ACCOUNT_JSON_B64=
  PUSH_MIRROR_EMAIL=1

Generate B64: ./deploy/scripts/firebase-service-account-b64.sh /path/to/key.json

--- CI frontend image (GitHub Environment variables) ---

Same VITE_FIREBASE_* names as backend/.env.example (staging + production environments)

--- Firebase Console ---

Add production + staging HTTPS domains under Authorized domains.

Tenant fcm_devices: applied on deploy via schema-migrate-all.
