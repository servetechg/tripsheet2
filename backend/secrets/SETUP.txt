Firebase Admin key (required for Send test browser push)
============================================================

The file firebase-admin.json is NOT in git. You must create it locally.

Steps:
1. Open https://console.firebase.google.com/ → project fleetquix-official
2. Project settings (gear) → Service accounts
3. Click "Generate new private key" → download JSON
4. Save the download AS this exact filename (same folder as this file):

   backend\secrets\firebase-admin.json

   Full path on your PC:
   C:\Users\USER\Desktop\hasnain\react\tripsheet2\backend\secrets\firebase-admin.json

5. Do NOT rename firebase-admin.json.example — use the downloaded file content.
6. Restart backend: cd backend && npm run start:dev
7. Look for log line: Firebase Admin initialized for FCM

If you already downloaded a file like fleetquix-official-xxxxx.json, move/copy it to firebase-admin.json
